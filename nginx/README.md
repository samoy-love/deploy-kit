# nginx

Здесь лежит **источник правды** по конфигурации nginx для всех проектов
samoy.love. Раньше он был только на сервере, а в репозиториях валялись копии
разной степени свежести — их больше нет.

```
sites/      по файлу на домен, ровно то, что подключено в sites-enabled
snippets/   общие куски, включаются из sites/
```

## Правила

**Один файл — один домен.** Общий конфиг на два сайта уже приводил к тому,
что выкатка лаунчера роняла соседний сайт. Проект правит только свой файл.

**`http2` только формой `listen 443 ssl http2`.** На сервере nginx 1.24,
отдельной директивы `http2 on` там ещё нет — она валит `nginx -t`.

**`add_header` не наследуется.** Как только в `location` появился хоть один
`add_header`, все серверные заголовки в этом `location` перестают отдаваться.
Поэтому заголовки безопасности подключаются сниппетом **в каждом** `location`,
а не один раз на уровне `server`.

**ACME трогать нельзя.** Блок `/.well-known/acme-challenge/` смотрит в каталог,
куда пишет certbot. Если подменить его на каталог релиза, продление сертификата
молча перестанет работать — узнаете через три месяца.

## Как менять

Правки — в этот каталог, дальше выкатка:

```bash
server/nginx-apply.sh --site sites/samoy.love.conf
```

Скрипт снимает состояние **до** правки, кладёт бэкап, проверяет `nginx -t`
и откатывается сам, если проверка не прошла. Руками в `/etc/nginx` не ходим:
файл на сервере и файл здесь должны совпадать.

## Известные расхождения

Снимок снят с живого сервера как есть, без причёсывания — сначала зафиксировать,
потом нормализовать. Что видно уже сейчас:

- пути разъехались: `/var/www/site/current` у лаунчера, `/var/www/metro/current`
  у метро, `/var/www/samoy.love/current` у главной;
- `metro.conf` отдаёт `robots.txt` из `/var/www/site` — то есть из каталога
  лаунчера, где его нет, и запрос сваливается в HTML;
- `robots.txt` есть только у главной и лаунчера, у остальных 404;
- `chillhub-launcher.conf` — 1240 строк, из них больше половины комментарии.

Нормализация — отдельным шагом, чтобы падение можно было связать с одной правкой.
